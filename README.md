# Saved Manager API

REST API для приложения KMP Saved App. Реализует эндпоинты для аутентификации пользователей, управления папками, категоризации закладок и анализа ссылок с помощью AI.

## Стек технологий

* **Язык:** Go 1.26
* **Фреймворк:** Gin
* **База данных:** PostgreSQL + GORM
* **AI-движок:** Ollama (Llama 3.2)
* **Авторизация:** JWT (Access & Refresh токены)

## Конфигурация

Перед запуском сервера необходимо создать файл переменных окружения:

1. Скопируйте пример конфигурации:
   ```bash
   cp .env.example .env
   ```
2. Откройте `.env` и при необходимости скорректируйте параметры (доступы к БД, JWT-секреты, настройки Ollama).

## Запуск приложения

Проект использует Docker Compose для одновременного запуска Go-сервера, PostgreSQL и Ollama.

1. Запустить все контейнеры в терминале из корня проекта:
   ```bash
   docker-compose up -d
   ```

2. Загрузить требуемую AI-модель для Ollama:
   ```bash
   docker exec -it myserver-ollama ollama pull llama3.2
   ```
   
API будет доступно по адресу `http://localhost:8080`.

## Документация API

Спецификация API находится в файле `swagger.yaml` в корне репозитория.
